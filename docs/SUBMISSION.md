# SkinPilot AI — 提交材料草稿
> 状态：草稿。黑客松页面无法自动读取，具体提交项需以官方要求为准，请核对后补充 [ ] 处。

**一句话：** 把碎片化护肤教程变成个性化、可跟练、可验证的护肤学习流程。
**问题：** 用户看过教程却学不会：流程碎片、产品不适配、来源不可信、缺少练习反馈。
**方案：** 教程解析（区分“明确”与“AI 推断”）→ 个性化 → AI 导师逐步跟练 → 理解测试 → 保存复用。
**学习闭环度量：** 自报完成 / 测试通过 / 独立复现三档，只有后者计入独立完成率。

## 当前真实可用
- Next.js 项目：文字教程 → 结构化步骤（服务端 OpenAI + zod）、邮箱登录、Supabase 落库（RLS）、AI 教练问答、AI 理解测试、Dashboard、10 个单元测试通过。
## 仍是模拟 / 未完成
- 交互原型（prototype.html）为预置演示数据；视频/链接解析、RAG 知识库与真实来源、产品成分库、实时摄像头指导均未实现；导师为插画形象，无语音。

## 2–3 分钟 Demo 脚本
1. 首页：选导师，填肤质与已有产品（触发成分冲突提醒）。
2. 导入演示教程，展示“视频明确 / AI 推断”。
3. 个性化方案（预算内、可跳过）。
4. 跟练：点 “Why this step?” 等按钮，导师回答。
5. 理解测试 → 如实选择完成度 → 进度页。
